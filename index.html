Projects

Things I have built.

  • Morse Code Decoder

    A handheld Morse decoder on a Seeed Studio XIAO ESP32 with a 0.96" 128x64 OLED. SW1 is dot (D0), SW2 is dash (D1), SW3 is clear (D2). Pause 1.2 seconds and the letter appears. Parts total $44.

    See it on GitHub

  • Fountain Pen Dipwell and Holder

    A holder for a Parker fountain pen, so you can use it as a dip pen without a cartridge or ink converter. 3D printed, sealed with epoxy, and made watertight with M4 heat inserts and screws. Fill it through the conical hole — no glitter ink, hand wash only. Parts total $45.

    See it on GitHub

  • Fountain Pen Ink Cartridge Dispenser

    A desk stand that holds fountain pen ink cartridges — push one out when you need to change ink, instead of digging through a drawer for the box. Made so I can work more efficiently with my fountain pen.

    See it on GitHub
